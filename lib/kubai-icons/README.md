# Blog line icons

Four upstream Kubai SF-style icons: folder, file-text, search, upload. Generated using the official kit renderer at stroke 2, outline, currentColor. line-icons.json contains rendered output and motion presets; line-motion.mjs is the unchanged upstream engine. line-runtime.js handles application events. Original license and copyright notices are retained.

Source: https://github.com/kubai087/kubai-icons/tree/main/styles/line

Official four-icon check: no findings. Desktop production screenshots reviewed. A real 390px mobile viewport reports scrollWidth 390 with no overflowing elements. Static icons remain visible while the motion module loads. Canvas content never replaces covers or article text.
