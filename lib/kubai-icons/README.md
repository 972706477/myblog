# Blog animated icons

Four functional icons are used: folder (projects), document (notes), search, and upload (Markdown import). Definitions and the original animation engine come from https://github.com/kubai087/kubai-icons and retain their copyright notices. See LICENSE for permitted use within this blog.

runtime.js combines the upstream engine and examples with a small React lifecycle adapter. All instances use blue #5393FF, unique SVG identifiers, hover/focus events, reduced-motion support and cleanup on unmount. Icons are decorative; existing labels provide accessible names.

Official self-check: 4 icons, no script errors or findings. Screenshots and measurement output are in the ignored .icon-check directory. The complete blog production build also passes. Full-page browser interaction has not yet been verified.
